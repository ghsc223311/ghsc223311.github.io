SQL UDF(User Defined Function)

問問ai說可以試試UDF :

當 MySQL 內建的 SQL 函數（如 SUM()、NOW()）不夠用時，開發者可以用 C 或 C++ 寫一個自訂的功能，編譯成動態連結庫檔案（在 Windows 上是 .dll，在 Linux 上是 .so

在滲透測試中，如果我們滿足了以下三個條件，UDF 就會變成一個威力巨大的提權漏洞:

  1. 已經知道 root 密碼並成功登入
  2. 資料庫服務是以高權限執行, MySQL 服務預設經常以 NT AUTHORITY\SYSTEM（系統最高權限）身分在背景運作
  3. 允許寫入外掛檔案, 如.dll
